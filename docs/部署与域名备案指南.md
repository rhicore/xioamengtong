# 图书定制采集系统：部署、域名与备案指南

更新时间：2026-10-05

本文记录当前项目的本地环境、CloudBase 部署、临时访问地址、域名购买、ICP 备案和后续发布流程。本文不包含任何 CloudBase API Key、密码或其他敏感信息。

## 1. 项目组成

```text
customer_web/    顾客上传与图片编辑网页
admin_web/       打印/客服人员使用的后台网页
backend_api/     顾客端和后台共用的 HTTP API
CloudBase        云托管、静态托管、数据库和云存储
```

线上调用链路：

```text
顾客浏览器 ─┐
            ├─> backend_api 云托管 ─> CloudBase 数据库 / 云存储
后台浏览器 ─┘
```

## 3. 本地开发环境

### macOS/Linux

建议使用 Node.js 20.19+ 或 22.12+。

```bash
cd backend_api
pnpm install --frozen-lockfile

cd ../customer_web
pnpm install --frozen-lockfile

cd ../admin_web
npm ci
```

本地环境文件：

```text
backend_api/.env
customer_web/.env.local
admin_web/.env.local
```

这些文件均被 `.gitignore` 忽略，不要提交到 GitHub。

分别在三个终端启动：

```bash
cd backend_api && pnpm start
cd customer_web && pnpm run dev
cd admin_web && npm run dev
```

本地前端默认访问：

```text
backend_api:  http://localhost:8787
customer_web: VITE_API_BASE_URL=http://localhost:8787
admin_web:    VITE_HTTP_API_BASE_URL=http://localhost:8787
```

本地后端如果要读写真实 CloudBase 数据，需要在 `backend_api/.env` 中填写 CloudBase 服务端 API Key。该密钥只能放在本地被忽略的环境文件或 CloudBase 云托管环境变量中，不能放入前端或 GitHub。

### Windows

Windows 原有的 PowerShell 流程继续兼容，具体命令见根目录 [README.md](../README.md)。Windows 和 macOS/Linux 共享同一套 Node.js 项目、环境变量名称和 CloudBase 配置。

## 4. 当前发布方式

### 登录 CloudBase CLI

本机使用 pnpm 临时运行 CLI，不要求全局安装：

```bash
pnpm dlx --package=@cloudbase/cli tcb login
```

### 发布后端

在项目根目录执行：

```bash
pnpm dlx --package=@cloudbase/cli tcb cloudrun deploy \
  --env-id xiaomengtong-d5g5zuan5ae97c4ea \
  --service-name notebook-backend-api \
  --source backend_api \
  --port 8787 \
  --open-access-types PUBLIC \
  --min-num 1 \
  --wait
```

云托管中的服务端环境变量需要在 CloudBase 控制台维护，至少包括：

```text
CLOUDBASE_ENV_ID
CLOUDBASE_APIKEY
ADMIN_CORS_ORIGINS
ADMIN_COOKIE_SAMESITE=None
```

### 构建和发布前端

先构建：

```bash
cd customer_web && pnpm run build
cd ../admin_web && npm run build
cd ..
```

再发布到 CloudBase Hosting：

```bash
pnpm dlx --package=@cloudbase/cli tcb hosting deploy admin_web/dist admin \
  -e xiaomengtong-d5g5zuan5ae97c4ea

pnpm dlx --package=@cloudbase/cli tcb hosting deploy customer_web/dist customer \
  -e xiaomengtong-d5g5zuan5ae97c4ea
```

发布前应确认生产构建中的 API 地址不是 `localhost`，并确认没有把 `.env`、`.env.local` 或 API Key 加入暂存区。

## 5. 域名购买

推荐直接在腾讯云购买，因为后续 DNS、SSL、备案和 CloudBase 在同一账号中管理：

[腾讯云域名注册](https://buy.cloud.tencent.com/domain)

购买时只需要选择“域名注册”，不需要购买服务器、轻量云或建站套餐。建议先购买一个主域名，例如：

```text
xiaomengtong.com
xiaomengtong.cn
xiaomengtongbook.com
```

具体是否可注册，以腾讯云页面实时查询结果为准。

购买前需要：

1. 完成腾讯云账号实名认证。
2. 创建域名信息模板。
3. 选择个人或企业主体，并确保域名所有者与备案主体一致。
4. 选择已审核通过的信息模板。
5. 付款前仔细核对域名拼写。

域名注册成功后通常不能修改，也不支持退款。域名实名信息模板一般需要 1～3 个工作日审核。

## 6. ICP 备案

如果网站面向中国大陆正式提供服务，需要办理 ICP 备案。CloudBase 官方也要求生产环境的自定义域名完成备案。

备案主体建议：

| 实际用途 | 建议备案主体 |
|---|---|
| 个人测试或个人非商业项目 | 个人 |
| 店铺、公司或实际业务使用 | 企业 |
| 后续可能收款、经营或对外接单 | 优先企业 |

备案基本顺序：

1. 域名完成注册和实名认证。
2. 腾讯云域名实名认证完成后，等待系统允许提交备案。
3. 进入腾讯云 ICP 备案控制台。
4. 选择“首次备案”“新增服务”或“接入备案”等正确类型。
5. 填写主体、负责人、网站名称、域名和网站服务信息。
6. 上传身份证或营业执照等材料，完成视频/短信核验。
7. 等待腾讯云初审和通信管理局审核。
8. 备案通过后，在网站底部显示 ICP 备案号，并链接到工信部备案网站。

腾讯云初审通常约 1～2 个工作日，管局审核可能最长约 20 个工作日，具体以所在省份要求为准。

备案资料需要提前准备：

- 个人或企业主体证件；
- 网站负责人和联系方式；
- 域名实名信息；
- 网站名称和网站内容说明；
- CloudBase 备案云资源信息；
- 网站隐私说明和基本业务介绍。

本项目会收集订单号和顾客上传的图片，正式上线前建议补充隐私说明、图片保存期限、客服联系方式和数据删除规则。

### 备案后的其他事项

- 网站上线后通常需要在 30 日内办理公安联网备案。
- 如果业务属于经营性互联网服务，可能还需要经营性 ICP 许可证或其他增值电信业务许可，需结合实际收费和经营模式向腾讯云备案客服或当地通信管理部门确认。

## 7. 域名绑定后的目标规划

理想的正式地址：

```text
www.你的域名.com      顾客端
admin.你的域名.com    后台
api.你的域名.com      后端 API
```

当前 Hosting 目录是后台在根路径、顾客端在 `/customer/`。绑定正式域名前，需要先决定是否：

1. 先保持当前结构：主域名访问后台，顾客端继续使用 `/customer/`；或
2. 调整发布目录，使顾客端成为主站，后台改到独立子域名或路径。

正式绑定时需要完成：

1. 准备 SSL 证书。
2. 在 CloudBase 静态托管或 HTTP 网关中添加前端域名。
3. 在 CloudRun 服务中添加 API 域名。
4. 按控制台提示添加域名归属校验 TXT 记录。
5. 按控制台提供的值添加 CNAME 解析。
6. 将 `ADMIN_CORS_ORIGINS` 改成正式前端域名。
7. 将两个前端的 API 地址改成 `https://api.你的域名.com`。
8. 重新构建、测试并发布前端和后端。

参考：

- [CloudBase 自定义域名配置](https://docs.cloudbase.net/service/custom-domain)
- [CloudBase 静态托管域名配置](https://docs.cloudbase.net/service/access-static-hosting)
- [腾讯云 ICP 备案流程](https://cloud.tencent.com/document/product/243/39038)
- [腾讯云备案后处理要求](https://cloud.tencent.com/document/product/243/61412)
