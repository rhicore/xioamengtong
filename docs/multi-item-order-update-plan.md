# 一单多组图片：最小更新方案

更新日期：2026-11-10。顾客端、后端及管理端已接通多组保存、重载、预览和分组下载，按确认后的版本提交并发布。

## 顾客操作

保留原来的三个步骤：输入订单号 → 选择类型并上传、裁切图片 → 确认提交。

只在原上传页增加：

1. “第 1 组 / 第 2 组”切换按钮，每组独立保存当前页面中的款式和正反面图片。
2. “添加一组”和“删除本组”，不同款式或不同图片时使用。
3. “本组数量”，同款同图印多本时使用，默认 1。
4. 多组时显示组数和总本数，仍由原来的“确认提交”按钮统一提交。

原来的页面配色、款式选项、图片位和制作锁定规则继续沿用。不增加独立清单页、核对页、自动草稿、图片复用或新的认证流程。

## 当前实现范围

启动 `customer_web` 后打开 `http://127.0.0.1:5173/`。查询、图片上传和提交均使用原来的真实 HTTP 接口。

没有独立预览模式、模拟订单、跳过保存的假提交或“后端尚未支持”的前端拦截。`?preview=multi-order` 不再改变页面行为。

原订单增加 `groups` 数组，每组保存稳定 ID、本册类型、数量和正反面图片 fileID。沿用原上传接口，每组上传后，原提交接口一次保存全部组；原查询接口返回所有组，按组获取图片。旧单按一组读取，原制作锁定规则不变。

管理端沿用原订单列表、图片弹窗和下载按钮。订单图片列按组显示款式、数量和缩略图；下载在订单目录内按组分目录，每组附订单信息和对应图片。旧订单保持原下载结构。
类型筛选匹配订单内任意一组，防止第二组及后续组被漏查；与其他筛选条件同时生效。

## 本次细化

点击裁切后进入黑色全屏编辑画面，支持单指移动、双指缩放及旋转、90° 旋转、重置与更换图片。裁切框固定 1704:2400，JPEG 导出固定 1704 × 2400。打开时居中铺满裁切框，长图裁掉上下多余部分，宽图裁掉左右多余部分；拖动、缩放及旋转时限制边界，让整个裁切框始终位于原图内部，不添加白边。取消裁切保留原图。
网页缩略图按圆角显示，与上传区及其他控件保持一致；全屏裁切框与实际导出的图片仍为完整直角矩形。

提交前逐组检查类型、图片与正整数数量，出错时定位到对应组。上传过程中保持组内容稳定，显示当前进度，避免重复提交。若后续组上传失败，保留前面组已上传的 fileID，重试只补未完成部分；所有组上传完成后统一保存订单。

本地演示与浏览器完整测试方式见 [tests/README.md](../tests/README.md)。
