# 业务逻辑流程

## 顾客操作

1. 顾客打开顾客网页，输入订单号并点击下一步。
2. 系统快速查询订单，并根据订单号外形推断平台；无法判断时显示“未知平台”，同时提示顾客检查订单号。
3. 顾客选择图片类型：
   - **两图**：上传正面和反面，共 2 张图。
   - **一张图**：只上传正面，共 1 张图。
4. 顾客点击图片框选择图片。再次点击已有图片会进入图片编辑器，可以更换图片、拖动位置和双指缩放。
5. 编辑器中提示：裁切会有 3—5mm 误差，重要文字和图案请远离照片四周边缘。
6. 顾客提交后，后端把裁切结果保存到云存储，把 fileID 写入订单记录，并显示：

   > 提交成功，小二给您加紧安排制作，请您耐心等待！

同一订单号再次进入时，页面会显示之前上传的图片，顾客可以修改图片类型或重新编辑后提交。

## 后台操作

1. 员工登录后台。
2. 在订单列表按订单号、平台、日期、图片类型和状态筛选。
3. 列表显示订单号、推断平台、图片类型、状态、图片缩略图和上传/修改时间。
4. 点击缩略图查看原图预览。
5. 选择订单后批量下载。压缩包按订单号分别建立文件夹，每个文件夹包含：
   - `订单信息.json`
   - `前.jpg`（存在正面图片时）
   - `后.jpg`（存在反面图片时）

## 服务边界

顾客网页和后台网页都只调用 `backend_api`，不直接访问 CloudBase 数据库或云存储。所有图片上传、临时 URL、权限校验和 ZIP 生成都在服务端完成。
